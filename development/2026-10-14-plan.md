## Landed skeleton contract (implementation slice, not feature acceptance)

The skeleton extracts the public HTTP adapter, Documents module and Preview module. Its interface
seams give callers leverage over key ownership, cursor capture and stream lifecycle; the deletion
test would put that complexity back into each HTTP caller if Documents disappeared. R2 is a true
external dependency with native and in-memory test adapters. Preview/extraction/search dependencies
are in-process; UI-to-Catalog is remote but owned. This locality is deliberate: no generic repository,
converter registry or persistent review-job framework was introduced.

`worker/src/contracts.ts` freezes metadata/filter/selection/delete/session JSON and separate
`PublicEnv` / `CatalogEnv` roles. Documents exports `createDocuments(bucket, publicOrigin)` returning
`create`, `page`, `resolve`, `remove`; it also exports `ObjectRef`, `ResolvedDocument`, `RemoveResult`,
`Documents`, and `isUploadId`. Keys remain server-only. Resolved bodies open once and must be consumed
or canceled; bounded reads use `maxBytes` or `range`, not both. R2 exceptions remain errors, never
successful empty pages. `resolve` orders owned keys lexicographically; legacy removal captures all
cursor pages before deleting batches of at most 1,000 keys. Baseline per-ID scans are retained; the
next Documents owner must bound anomalous groups while implementing full-corpus discovery.

Intentional unavailable operations: `Documents.page()` throws; `remove(id, expectedVersion)` throws
before storage access until immutable ID reservation/version checks are implemented. Versionless
legacy bearer removal still works. `extractText` returns explicit metadata-only coverage without
opening the body; `createSearchIndex().add/query` throw. Catalog returns private no-store/noindex
503 JSON for every route without storage, assets, or cookies. UI assets are inert placeholders.
`enhanceHtml(response, {id,title,publicUrl}): Promise<Response>` is pass-through: later runtime work
must vendor the actual vim-html sources, preserve baked identity/single injection, and use theme none.
Preview calls it for HTML page responses and generated wrappers, never raw/download.

### Frozen catalog HTTP contract for the next owners

All routes below live only on `CATALOG_ORIGIN`; public `/all-docs` redirects to that literal origin.
Success JSON uses `version: 1`; errors use `CatalogError`. No catalog secret belongs in browser code.
No route below is enabled by this skeleton. Catalog owns auth, exact-Origin/CSRF checks, request caps,
private headers, failure status codes and bounded orchestration; UI owns the frozen global review.

| Route | Request / response |
| --- | --- |
| `GET /all-docs` | Trusted shell or login view; never uploaded markup. |
| `GET /all-docs/session` | Authenticated bootstrap `SessionResponse = {version:1, csrfToken:string, expiresAt:string}`; unauthenticated 401. Expiry is UTC ISO 8601. |
| `POST /all-docs/session` | `LoginRequest = {password:string}` as JSON; form-encoded password may support the no-JS form. Success returns the same session fields (or a same-origin form redirect); auth/throttle errors remain private. |
| `DELETE /all-docs/session` | Authenticated exact-Origin/CSRF request, clears cookie; 204. |
| `GET /all-docs/api/documents?cursor=...` | `CatalogPage`; signed/validated cursor ownership remains inside Catalog. Continue even with zero items when nextCursor is non-null. |
| `GET /all-docs/api/documents/:id/text?version=...` | `TextRecord`; 409 on stale document version. No raw uploaded content or public markup returned. |
| `POST /all-docs/api/delete` | `DeleteBatchRequest = {version:1, items:SelectionRef[], confirmCount:number, confirmation:string}`; 1–100 unique refs, `confirmCount === items.length`, and `confirmation === "DELETE " + items.length + " documents"`. Returns `DeleteProgress` with per-ID `deleted/not-found/changed/failed`. |

UI reviews the entire frozen selection once, with exact global count/bytes/names/IDs/cutoff, then sends
explicit per-batch counts/confirmations. Never recompute a filter after review or silently select an
incomplete corpus. Preserve failed and unprocessed refs. This one bulk route supersedes the designer's
separate delete-review/delete-batch token proposal; no durable review state or signed delete jobs.
Session responses name **csrfToken** and **expiresAt** (not csrf or expiry). Auth transport headers:
`X-Docs-Catalog: 1` on JSON requests and `X-CSRF-Token` on authenticated mutations. Login validates
exact Origin independently of the authenticated mutation token; do not permit a cross-origin form.

`worker/src/search.ts` freezes `SearchWorkerRequest` / `SearchWorkerResponse` for the UI and search
owners. Every message has `{version:1,generation:number}`. Requests: `operation:"add"` with
`summary,text`; `operation:"query"` with `query,filter`; `operation:"clear"`. Replies:
`status:"ready"`; `status:"results"` with `hits`; or `status:"error"` with `code,message`.
Generation correlates replies, not credentials. UI ignores stale generations and terminates the
worker/clears private content on logout. Search owner keeps the protocol while filling its module.
